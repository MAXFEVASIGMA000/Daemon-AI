# Daemon-AI

Daemon-AI is a local, open-source AI coding assistant built to bring a powerful developer companion directly to your desktop.

Powered by local LLMs through Ollama, Daemon is designed to work like a lightweight OpenCode-style agent with a custom GUI, coding tools, and system integration.

## Features

* 🤖 Local AI assistant powered by Llama 3.1
* 💻 Coding-focused chat interface
* 🖥️ OpenCode-inspired developer workspace
* 📂 Project and file awareness
* ✏️ AI-assisted coding workflows
* 🛠️ Tool system for interacting with your machine
* 🚀 Custom dark-themed PySide6 GUI
* 📊 System monitoring (CPU/RAM)
* 🔒 Local-first design

## Vision

Daemon-AI aims to become a personal AI development environment that can help you build projects, understand code, manage files, and automate tasks while keeping everything running locally.

## Planned Features

* Advanced code editing
* Autonomous coding workflows
* Terminal integration
* Long-term memory
* Plugin system
* Improved agent tools
* Project management features

Daemon is a work-in-progress project focused on exploring what a personal local AI developer assistant can become.
